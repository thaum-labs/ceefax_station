Download for Mac

Pick the installer that matches your Mac. Both require macOS 13 Ventura or later.

Apple Silicon

M1, M2, M3, M4, and later. Native arm64 package.

Download Apple Silicon .pkg

Apple menu → About This Mac shows a chip name like “Apple M2”.

Intel

Intel x86_64 Macs, including macOS 13 Ventura.

Download Intel .pkg

About This Mac shows an Intel processor. This package also runs on Apple Silicon via Rosetta.

After install, run ceefaxstation in Terminal, or open Ceefax Station from Applications.

If macOS blocks the package, open System Settings → Privacy & Security and choose Open Anyway.
